# Zine

Zine 0.14.0 (pinned release binary, musl static, SHA-256 checked, amd64 and arm64) on Ubuntu 24.04, benchmarked by SSGBerk. Zine renders SuperMD (a Markdown dialect) with Ziggy front matter (`---` plus `.title = "..."`), which none of the canonical content types produces. `build.sh` therefore generates the posts as plain markdown (`none`) into `src/posts`, and the timed `build_command` converts them in one awk process (`zine-convert.awk`, no per-post forks) into `content/posts/<name>.smd` before running `zine release -o public`. The conversion is part of the timed build, as the `SUMMARY.md` listing is for mdBook. It writes the front matter (`.title` from the file name, `.date` from its date prefix, `.layout`), moves headings up one level (a SuperMD document must start at heading level 1; `zine.ziggy` sets `headings_h2` so they still render as `<h2>`/`<h3>`) and turns `~~~ text` fences into plain fences (SuperMD rejects the language `text`).

Each post must render to `public/posts/*/index.html`; the verification step checks the count equals the requested number of files. The reference assets (`ssgberk.css`, `ssgberk.png`) are shipped byte-identical in `src/assets/assets/` and installed through `static_assets`, so the `/assets/ssgberk.png` image in every post resolves. Layouts are minimal: `post.shtml` renders only its post, `posts.shtml` and `index.shtml` list every post (no pagination). Zine writes no cache between runs, so `cache_folders` is empty. Run it with `./ssgberk --test zine -nf 10` from the toolset repository.
