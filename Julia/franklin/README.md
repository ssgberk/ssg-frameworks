# Franklin

Franklin.jl 0.10.97 on Julia 1.13.1 (official release tarball) on Ubuntu 24.04, benchmarked by SSGBerk. Franklin is pinned by `src/Project.toml` and `src/Manifest.toml`; the packages are installed and precompiled in the image (`JULIA_DEPOT_PATH=/opt/julia-depot`), so the timed build is offline and does not recompile. `build.sh` generates the posts into `src/posts` (`YYYY-MM-DD-NN.md`), then times `julia --project -e 'using Franklin; optimize(minify=false, prerender=false)'`, a single build without a server; Julia start-up is part of the timing, as in real use. Each post must render to `__site/posts/*/index.html` (the verification step checks the count equals the requested number of files). Run it with `./ssgberk --test franklin -nf 10` from the toolset repository.

Franklin evaluates `+++` front matter as Julia code, so the benchmark's TOML datetime values do not parse. The content type is therefore `none`: posts carry no front matter and the title and date shown on pages come from the file name (`utils.jl`). Posts have no author, tags or summary. The index (`index.md`, `{{postlist}}`) lists every post; post pages render only their own title, date and content. RSS, sitemap and robots.txt are disabled; the 404 page is `404.md`. Franklin writes no cache outside `__site`.
