# JBake

JBake 2.7.0 (binary distribution zip) on OpenJDK 21 JRE (Ubuntu 24.04 `openjdk-21-jre-headless`, amd64/arm64), benchmarked by SSGBerk. `build.sh` generates the posts into `src/raw/posts` (content type `3minus`), then times `build_command`: one `awk` pass (`convert.awk`) rewrites the YAML front matter of every post into JBake's `key=value` + `~~~~~~` header in `content/posts`, followed by `jbake -b . output` (FreeMarker templates in `templates/`). Each post must render to `output/posts/*.html` (the verification step checks the count equals the requested number of files). The timed build runs offline. Run it with `./ssgberk --test jbake -nf 10` from the toolset repository.

Deviations: JBake does not read YAML front matter (only its own header), so the header conversion is part of the timed build, as a real JBake site would need it. `content` and `cache` (the embedded OrientDB store JBake writes next to the sources) are listed in `cache_folders` and removed before each run. Archive, feed, sitemap and tag pages are disabled in `jbake.properties`; no 404 page is rendered. `assets/ssgberk.css` and `ssgberk.png` live in `src/assets/assets` (JBake copies `assets/` into the output root).
