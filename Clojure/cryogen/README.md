# Cryogen

Cryogen 0.5.1 (`cryogen-core` 0.5.1 with `cryogen-flexmark` 0.1.5, Clojure 1.12.5) on Ubuntu 24.04 with Temurin JRE 25 and the Clojure CLI 1.12.6.1673, benchmarked by SSGBerk. All dependencies are resolved into `~/.m2` and the classpath is cached (`.cpcache`) while the image is built, so the timed build runs offline. `build.sh` generates the posts into `posts/` (`3minus` front matter), then times `sh -c 'mkdir -p content/md/posts public && printf "%s\n" posts/*.md | awk -f cryogen-convert.awk && clojure -M:build'`; each post must render to `public/posts/*/index.html`. The JVM start and the Clojure namespace load are part of the timed build, as in real use.

Cryogen posts start with an EDN metadata map (`{:title ... :layout :post}`) instead of YAML front matter, so none of the canonical content types fits. `cryogen-convert.awk` turns the generated YAML into that map in one awk process for all posts (file names are piped in with a shell builtin; no per-post fork) and writes them to `content/md/posts`, Cryogen's markdown folder. That folder is listed in `cache_folders` and the conversion is part of the timed build. `:tag-order` repeats the tags as a vector because Cryogen turns `:tags` into a set and loses the front matter order.

The theme `ssgberk` (`themes/ssgberk/html`) renders the reference pages with Selmer: `base.html` plus `header.html`/`footer.html` includes, `post.html`, and `previews.html` as the index. The index uses Cryogen's preview mode with one page (`:posts-per-page` is huge, `:blocks-per-preview` 1), so it lists every post without pagination; the list is sorted in the template with `sort-by-reversed`. `404.html` is a static file Cryogen copies verbatim from the theme. The reference stylesheet and image are copied from `content/assets` (`:resources ["assets"]`).

Cryogen always writes the tag pages (`tags/<tag>/`, `tags/`), `archives/`, `sitemap.xml` and `feed.xml`; none of these can be switched off in `config.edn`, so they are minimal templates and count as unavoidable extra output. `:author-root-uri` is unset (no author pages), the filtered RSS feeds (`:rss-filters`) are off, and flexmark does no syntax highlighting. The JVM uses `-Duser.timezone=UTC` so post dates match the front matter.

Cryogen reports template errors on stdout and still exits 0; the verification step only counts post pages, so check the index when changing templates. Run it with `./ssgberk --test cryogen -nf 10` from the toolset repository.
