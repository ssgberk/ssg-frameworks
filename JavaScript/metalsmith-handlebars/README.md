# Metalsmith + Handlebars

Metalsmith 2.7.0 with @metalsmith/markdown, @metalsmith/permalinks and @metalsmith/layouts (handlebars templates) on Ubuntu 24.04 with Node 24.21.0, benchmarked by SSGBerk. `build.sh` generates the posts into `src/content/posts`, then times `node index.js`; each post must render to `build/posts/*/index.html` (the verification step checks the count equals the requested number of files). A single `build/index.html` lists all posts. Dependencies are installed with `npm ci` from the committed `package-lock.json`. Run it with `./ssgberk --test metalsmith-handlebars -nf 10` from the toolset repository.
