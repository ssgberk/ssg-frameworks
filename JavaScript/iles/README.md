# îles

îles 0.10.0 on Ubuntu 24.04 with Node 24.21.0, benchmarked by SSGBerk. `build.sh` generates the posts into `src/pages/posts` (Markdown with `title`/`date` front matter), then times `npx iles build`; each post must render to `dist/posts/*.html` (the verification step checks the count equals the requested number of files; `index.html` sits outside `posts/` and does not match the glob). The site has one bare layout (`layouts/default.vue`, which renders only the post title and content) and one index page (`pages/index.vue`) listing every post through `import.meta.glob('./posts/*.md')`. `srcDir` is the project root (`iles.config.ts`) and `remark-gfm` enables tables. Dependencies are installed with `npm ci` from the committed `package-lock.json`. `cache_folders` clears `node_modules/.vite` and `node_modules/.cache` between timed runs; a production build does not create them, so they are defensive. The timed build needs no network (checked with `docker run --network none`). Run it with `./ssgberk --test iles -nf 10` from the toolset repository.

The build also writes `components.d.ts` and `composables.d.ts` (auto-import typings) into the project directory, outside the output folder.
