# Vike

Vike 0.4.267 (`vike-react` 0.6.29, React 19.3.0, `marked` 18.1.0, Vite 8.3.2) on Ubuntu 24.04 with Node 24.21.0, benchmarked by SSGBerk. `build.sh` generates the posts into `src/posts` (Markdown with `title`/`date` front matter, `3minus`), then times `npx vike build --logLevel silent`; each post must render to `dist/client/posts/*/index.html` (the verification step checks the count equals the requested number of files). The site is one post route (`pages/posts/@slug`, whose `+data.js` reads the post through `import.meta.glob('/src/posts/*.md', { query: '?raw' })` and renders it with `marked`; `+onBeforePrerenderStart.js` returns every post URL) and one index page listing every post. `prerender: true` and `trailingSlash: true` are set in `pages/+config.js`. `reference/assets/ssgberk.{css,png}` are shipped in `public/assets`. Dependencies are installed with `npm ci` from the committed `package-lock.json`; `cache_folders` clears `node_modules/.vite` between timed runs; telemetry is disabled with `DO_NOT_TRACK=1`. Run it with `./ssgberk --test vike -nf 10` from the toolset repository.

Notes: the timed command is `vike build` (the Vike CLI); plain `vite build` does not run the prerender step with this setup. Besides each post's `index.html`, Vike writes an `index.pageContext.json` next to every page, which counts in the output size.
