# Analog

Analog 2.8.0 (`@analogjs/platform`, `@analogjs/content`, `@analogjs/router`) on Angular 22.2.1 and Vite 8.3.2, on Ubuntu 24.04 with Node 24.21.0, benchmarked by SSGBerk. `build.sh` generates the posts into `src/content/posts` (markdown with YAML front matter, rendered by `@analogjs/content`), then times `npx vite build`; each post must render to `dist/analog/public/posts/*/index.html` (the verification step checks the count equals the requested number of files). The site is a bare Angular root component, one post page (`pages/posts/[slug].page.ts`, `injectContent` + `MarkdownComponent`, title + content only) and one index (`injectContentFiles`) listing every post slug. `vite.config.ts` lists `/` plus one route per post file in `prerender.routes` with `static: true`, so there is no SSR server in the output. Dependencies are installed with `npm ci` from the committed `package-lock.json`; `cache_folders` clears `dist`, `node_modules/.vite`, `.angular/cache` and `node_modules/.cache` between timed runs so every run is a cold build; Angular CLI analytics are disabled with `NG_CLI_ANALYTICS=false`. Run it with `./ssgberk --test analog -nf 10` from the toolset repository.

Timed command uses the realistic invocation (`npx vite build`), which includes ~0.1-0.4 s wrapper startup.

The timed build compiles the Angular app for the client and the server (SSR renderer used for prerendering) and runs the Nitro prerender; `dist/client`, `dist/ssr` and `dist/.nitro` are written next to `dist/analog/public`; `dist` is listed in `cache_folders`, so the whole directory is wiped between timed runs and only the site files in `dist/analog/public` are counted. Markdown is converted to HTML at build time by Analog's content plugin using `marked` with the Prism highlighter (the plugin only compiles markdown when a highlighter is configured).
