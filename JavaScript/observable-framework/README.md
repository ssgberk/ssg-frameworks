# Observable Framework

@observablehq/framework 1.13.4 on Ubuntu 24.04 with Node 24.21.0, benchmarked by SSGBerk. `build.sh` generates the posts into `src/src/posts` (the Framework source root is `src` inside the project directory; Markdown with `title`/`date` front matter), then times `npx observable build`; each post must render to `dist/posts/*.html` (the verification step checks the count equals the requested number of files). `observablehq.config.js` sets `pager: false`, `sidebar: false`, `toc: false`, `search: false`, `footer: ""` and `header: ""`, so a post page shows only its content. The index (`index.md`) lists every post from a build-time data loader (`posts.json.js`, run by Framework during the build, read through `FileAttachment("posts.json")`) and a plain DOM cell (no `htl` import), so no pre-processing step is timed outside the generator. Dependencies are installed with `npm ci` from the committed `package-lock.json`. `OBSERVABLE_TELEMETRY_DISABLE=true` is set in the image. `cache_folders` clears `src/.observablehq/cache/posts.json` (the data-loader output) and `node_modules/.cache` between timed runs. Run it with `./ssgberk --test observable-framework -nf 10` from the toolset repository.

Timed command uses the realistic invocation (`npx observable …`), which includes ~0.1–0.4 s wrapper startup. The build includes the Rollup bundling of the client runtime and the data loader execution; this is inherent to the generator and allowed.

Offline timed build: Framework resolves its built-in libraries (`npm:<lib>@latest`, e.g. d3, echarts, react) through the npm registry and caches them under `src/.observablehq/cache/_npm` and `_observablehq`. The dockerfile runs one untimed `observable build` on a generated post after `npm ci`, so those modules are resolved once at image build and kept like `node_modules`; the timed build needs no network (verified with `docker run --network none`). Framework 1.13.4 has no option to pin these `@latest` versions, so the resolved versions are those current at image build time; the lockfile pins only Framework itself.
