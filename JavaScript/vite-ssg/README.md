# vite-ssg

vite-ssg 28.3.0 (Vue 3.5.43, vue-router 5.4.0, `unplugin-vue-markdown` 32.1.1, `@vitejs/plugin-vue` 6.0.9, Vite 8.3.4) on Ubuntu 24.04 with Node 24.21.0, benchmarked by SSGBerk. `build.sh` generates the posts into `src/posts` (Markdown with `title`/`date` front matter, `3minus`), then times `npx vite-ssg build`; each post must render to `dist/posts/*.html` (the verification step checks the count equals the requested number of files). Markdown files are compiled to Vue components by `unplugin-vue-markdown`; routes are built in `src/main.js` from `import.meta.glob('./posts/*.md')` (one static route per post, so vite-ssg prerenders each one) plus an index route (`Index.vue`) listing every post slug. The app shell is a bare `App.vue` with a `RouterView`; post titles from front matter are not rendered as a heading (the body carries its own headings). `public/assets/ssgberk.{css,png}` are the reference assets. Dependencies are installed with `npm ci` from the committed `package-lock.json`; `cache_folders` clears `node_modules/.vite` and `node_modules/.vite-temp` between timed runs. Run it with `./ssgberk --test vite-ssg -nf 10` from the toolset repository.

The timed command is the realistic invocation (`npx vite-ssg build`), which includes ~0.1-0.4 s wrapper startup. The build does a client bundle plus an SSR bundle pass before prerendering; this is inherent to vite-ssg.
