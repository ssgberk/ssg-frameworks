# TanStack Start

TanStack Start 1.168.60 (`@tanstack/react-router` 1.170.41, React 19.3.0, Vite 8.3.4, `marked` 18.1.0, `front-matter` 4.0.2) on Ubuntu 24.04 with Node 24.21.0, benchmarked by SSGBerk. `build.sh` generates the posts into `src/posts` (Markdown with `title`/`date` front matter, `3minus`), then times `npx vite build --logLevel silent`; each post must prerender to `dist/client/posts/*/index.html` (the verification step checks the count equals the requested number of files). The site is a bare root route, one post route (`routes/posts/$slug`) and one index route listing every post. Posts are read at build time with `import.meta.glob('/src/posts/*.md', { query: '?raw' })` inside `createServerFn` handlers and rendered with `marked`; the `tanstackStart({ prerender: { enabled: true, crawlLinks: true } })` option renders `/` and every post linked from it to static HTML, so no server is needed. `reference/assets/ssgberk.{css,png}` are shipped in `public/assets`. Dependencies are installed with `npm ci` from the committed `package-lock.json`; `cache_folders` clears `.tanstack`, `node_modules/.vite` and `dist` between timed runs. The timed build makes no network access (checked with `docker run --network none`). Run it with `./ssgberk --test tanstack-start -nf 10` from the toolset repository.

Deviations: `src/routeTree.gen.ts` is generated by the build (not committed). The build also emits `dist/server` and client JS bundles; only `dist/client` is counted as output. Timed command uses the realistic invocation (`npx vite …`), which includes ~0.1-0.4 s wrapper startup.
