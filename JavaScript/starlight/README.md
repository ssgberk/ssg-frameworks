# Starlight

Starlight 0.42.5 (`@astrojs/starlight`) on Astro 7.3.5, Ubuntu 24.04 and Node 24.21.0, benchmarked by SSGBerk. `build.sh` generates the posts into `src/src/content/docs/posts` (Starlight's `docs` collection, content type `3minus`; the generated front matter already carries the `title` Starlight requires), then times `npx astro build --silent`; each post must render to `dist/posts/*/index.html` (the verification step checks the count equals the requested number of files). `src/src/content/docs/index.mdx` lists every post through `PostList.astro`. Dependencies are installed with `npm ci` from the committed `package-lock.json`; `cache_folders` clears `.astro`, `node_modules/.astro` and `node_modules/.vite` between timed runs so every run is a cold build; telemetry is disabled with `ASTRO_TELEMETRY_DISABLED=1`. Run it with `./ssgberk --test starlight -nf 10` from the toolset repository.

Deviations to keep a post page showing only its post: Pagefind search, table of contents and prev/next pagination are turned off in `astro.config.mjs`, the `sidebar` is empty and the `Sidebar` component is overridden with an empty one. Starlight's header (site title, theme selector) and footer remain; they list no other posts. The reference assets are in `src/public/assets/` (byte-identical copies, force-added because `public/` is git-ignored).

Timed command uses the realistic invocation (`npx astro …`), which includes ~0.1–0.4 s wrapper startup. The timed build includes Astro's Vite bundler pass and Starlight's route generation, which are inherent to the generator.
